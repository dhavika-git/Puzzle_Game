# Puzzle Game

A simple Python-based fruit guessing game where the player gets 3 attempts to guess a randomly selected fruit.

## How It Works

- The game randomly selects a fruit from a predefined list.
- It displays:
  - First letter of the fruit
  - Last letter of the fruit
  - Total number of characters
- The player gets **3 attempts** to guess the fruit.
- If the guess is incorrect, the game provides a hint showing the correctly positioned letters.
- The game ends when the player guesses correctly or uses all 3 attempts.

## Technologies Used

- Python
- Random Module
